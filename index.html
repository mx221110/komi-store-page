🪟 Windows

使用 Scoop 或 WinGet 安装，也可直接下载安装包。

scoop bucket add komi-store https://github.com/komi-store/komi-store-scoop-bucket scoop install komi-store/komi-store
winget install zed.rainxch.githubstore

🍎 macOS

推荐使用 Homebrew 安装。若提示无法验证，请在「系统设置 → 隐私与安全性」中允许。

brew tap komi-store/komi-store brew install --cask komi-store
